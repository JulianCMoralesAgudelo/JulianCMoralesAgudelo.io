# Portafolio profesional — Julián Camilo Morales

Sitio web personal y hoja de vida de Julián Camilo Morales Agudelo, analista de bases de datos con experiencia en Oracle, SQL Server, seguridad y automatización.

## Uso local

No requiere dependencias ni compilación. Abre `index.html` en el navegador o sírvelo con cualquier servidor HTTP estático.

## Estructura

- `index.html`: contenido y estructura semántica.
- `styles.css`: diseño responsive y estilos de impresión.
- `script.js`: año automático y acción para imprimir el CV.
- `assets/social-preview.png`: imagen para compartir el sitio en redes.

Compatible con GitHub Pages y cualquier alojamiento estático.
